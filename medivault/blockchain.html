Blockchain Network

Store the IPFS CID on Ethereum blockchain via MetaMask — supports Ganache (local) and Sepolia (testnet).

Select Network:
Not Connected
Ganache Local — Requires Ganache running on http://127.0.0.1:7545 and contract deployed via node deploy.js. MetaMask must be switched to Ganache Local (Chain 1337).
Sepolia Testnet — Uses Ethereum Sepolia (Chain 11155111). Contract must be deployed on Sepolia separately. Get free SepoliaETH from sepoliafaucet.com. MetaMask must be switched to Sepolia.
One-Time MetaMask Setup
  1. Open MetaMask → Settings → Security & Privacy → Turn Blockaid OFF
  2. Select the correct network using the switcher above
  3. Use the Wallet toggle to connect, then confirm the transaction
