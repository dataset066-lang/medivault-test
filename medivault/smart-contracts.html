🔒 Access Policy Enforcement
  • All access control changes are recorded on-chain and in the audit log.
  • Role assignments require the Admin wallet to be connected via MetaMask.
  • Patient records are encrypted; only holders of the AES key can decrypt.
  • IPFS CIDs are stored on-chain but content requires the decryption key.
  • SHA-256 hash ensures content integrity even if the IPFS file is replaced.
